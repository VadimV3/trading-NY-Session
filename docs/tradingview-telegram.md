# TradingView → Telegram: настройка и проверка

Подготовлен strategies/orb-fade/v1.3-telegram.pine. Код не скомпилирован в аккаунте, бот не создан и доставка пока не проверена. Брокер не подключён. TEST/LIVE — подписи уведомлений, не переключатель торгового сервера.

## Создать бота

1. Открыть официальный @BotFather в Telegram, отправить /newbot, задать имя и свободный username с окончанием bot.
2. Сохранить полученный токен приватно. Не вставлять в Pine, GitHub, сообщения этого чата или скриншоты.
3. Открыть нового бота и нажать Start. Для группы добавить его в группу; для канала нужны права публикации.
4. Получить chat_id своего чата через getUpdates Telegram Bot API после сообщения боту. Для приватного выполнения использовать локальную команду с безопасным вводом токена или доверенный API-клиент; токен не передавать сторонним ботам для определения ID. Для темы группы нужен также message_thread_id. Название темы само по себе её не выбирает.

## Настройка TradingView

1. Включить 2FA; проверить доступность Webhook URL в своём тарифе.
2. Добавить v1.3 на нужный символ M5. Указать Signal title = NAS100 NY ORB Fade, Notification mode = TEST, chat_id и Topic ID (0 для обычного чата). Выключить фильтр дат для будущих событий.
3. Создать alert с названием NAS100 NY ORB Fade | TEST | M5. Condition: только вызовы alert() этой стратегии. Не выбирать order fills вместе с alert(): это другой формат сообщений и возможные дубли.
4. Webhook URL: https://api.telegram.org/bot<TOKEN>/sendMessage — подставить токен приватно в интерфейсе. Код сам формирует JSON с chat_id и text. Токена в теле нет. Такой URL является секретом; скрывать на скриншотах и не сохранять в Git.
5. Для проверки доставки включить Send connection test, создать отдельный временный alert. На следующем realtime-обновлении придёт TEST CONNECTION / NO TRADE. При закрытом рынке обновления NAS100 может не быть; для проверки транспорта можно использовать отдельный временный график M5 активного рынка. Это не тест стратегии на крипте.
6. После теста удалить временный alert, выключить Send connection test и создать основной alert заново. Старый alert хранит снимок кода/настроек, простая смена Inputs на графике его не обновляет.

## Пример сообщения (условные цены, не сигнал к сделке)

[TEST] NAS100 NY ORB Fade | LONG
Инструмент: FOREXCOM:NAS100
Таймфрейм: M5
Вход-ориентир: 28000
SL: 27950
TP1 (2R): 28100
TP2 (3R): 28150
TP3 (4R): 28200
Время NY: 2026-11-16 10:00
Объём выбирается вручную. Цены источника графика.

## Перед демо-входом

- [ ] Сообщение TEST получено, время и инструмент совпадают с графиком; повторного сигнала на тот же бар нет.
- [ ] Свеча M5 закрылась, сигнал свежий, текущая цена ещё позволяет выполнить план. Сигнальный close не гарантирует цену исполнения.
- [ ] У брокера выбран правильный NAS100 CFD. Проверены различия FOREX.com и Bybit; уровни QQQ не используются для NAS100.
- [ ] SL находится ниже входа для LONG и выше для SHORT. Тейки расположены в противоположную сторону от стопа.
- [ ] Лоты выбраны по фактическому стопу, стоимости пункта и издержкам, проверены минимальный лот, шаг и маржа.
- [ ] На демо выставлен защитный SL и три частичных выхода по трети, если минимальный объём позволяет деление. После TP стоп автоматически не переносится.
- [ ] Остаток закрывается в 11:30 America/New_York согласно тестовой модели. Текущий Telegram alert сообщает только вход, а не фактические исполнения или напоминание выхода.
- [ ] Сохранены время сообщения/исполнения, реальные цены, скриншот и причина выхода. Проверена доставка с выключенным компьютером.

## Переход к LIVE

Сначала сверить демо-сигналы с графиком и исполнением: отсутствуют пропуски/дубли, правильно работают SL и частичные выходы. Затем удалить/остановить TEST alert, выбрать LIVE, отключить проверочное сообщение и создать новый alert. Это включает только уведомления с подписью LIVE. Реальный счёт у брокера переключается отдельно пользователем. Автоматическое исполнение NAS100 Bybit CFD/MT5 через этот бот не реализовано; сервер не нужен для маршрута TradingView → Telegram → ручной вход.

## Линии и метки

Оранжевая — OR High, голубая — OR Low, диапазон 09:30–09:45 NY. Серая — close сигнала (ориентир входа). Красная — SL. Салатовая — TP1 2R, зелёная — TP2 3R, бирюзовая — TP3 4R. Уровни сохраняются на графике после выхода до следующей сессии: линия не означает открытую позицию.

ORB +3 / -3 — покупка/продажа трёх тестовых единиц. -1 при LONG — продажа одной единицы для частичного выхода; +1 при SHORT — покупка для закрытия. Это объём, не доллары и не R. TP1 / SL — имя пары выходных ордеров, не доказательство срабатывания тейка. 11:30 NY — выход по времени. Диагональный голубой канал, скользящие линии и нижняя гистограмма не принадлежат этому скрипту.
