# NY ORB Fade v1.5 — indicator with virtual 3R statistics

Scope: one NY session, no trading orders. This is a separate indicator from strategy v1.3 and signals v1.4. Default OR 09:30–09:45, first closing breakout 09:45–10:30, strict return within 6 M5 bars, inside both boundaries, and one entry per day. Opposite-edge close cancels setup. Input allows wider wait and entry window, bounded by 09:45–11:30. New day builds a new OR. Old OR remains a drawing reference only, not a tradable multi-session level.

Virtual entry = confirmed signal close. Hidden SL = breakout extreme including the return candle plus 2 ticks; hidden TP = 3 times initial distance. Target and stop lines are not plotted. Exit monitoring begins on the next bar, never on the signal bar. Stop/target exit is recognized from M5 OHLC and reported at the bar close, not instant broker execution. Time exit at 11:30 NY if no earlier model exit. No fees, spread, slippage, size or live account data. These statistics cannot be compared directly to v1.3 next-bar entries or interpreted as $500 returns.

Gap at bar open beyond SL: model fill at open; gap beyond TP: conservative fill at target. If both levels touched within one candle without a decisive opening gap, outcome is ambiguous. A missing 11:30 bar / next day encountered with active state becomes DATA GAP. Both are counted but excluded from performance and reset the virtual position. No invented favorable intrabar path. Target event over the bar is evaluated before time close on that same bar.

Table: setup counters cover all loaded history. Performance covers the LAST 20 COMPLETED virtual positions (editable), including ambiguous/data-gap events in the window. Active position excluded. TP percentage denominator = determinate outcomes, including time exits. Positive percentage counts TP/SL/TIME records with R>0 (a time exit may be positive without reaching 3R). Net/mean R and closed-result R drawdown exclude uncertain records. This exclusion can bias the sample if many uncertain events: review their count. Time exits count as not reaching target. No claim of profitability or full-history maximum drawdown. Recalculation depends on loaded history and Inputs.

Chart: two OR boundaries and BUY/SELL/EXIT only; optional diagnostic markers. EXIT? denotes unresolved model result. No SL/TP graphics and no broker orders. Future multi-session support needs a separate version specifying age, replacement, overlap, entry windows and invalidation. A range being traversed is not a universal validity rule.

Validation: source/static checks and 11 independent Python virtual-outcome/rolling-window assertions. No Pine compiler, platform backtest, market-data replay or end-to-end notification test performed.
