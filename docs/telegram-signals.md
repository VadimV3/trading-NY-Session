# Telegram: сигналы без объёма

Исходник: signals/ny-orb-fade-v1.1-levels.pine. Отдельный indicator: LONG/SHORT, ticker с provider, M5, вход-ориентир (close подтверждённой свечи), SL, TP (2R по умолчанию), расстояние до SL и время NY/UTC. Лоты, капитал и риск% удалены. Размер позиции не блокирует сигналы.

1. Открыть нужный инструмент M5, вставить код, сохранить и запустить.
2. Создать Custom Alert на alert() calls этого индикатора по закрытию бара. Статические alertcondition LONG/SHORT не содержат динамических уровней; выбрать alert() для полного сообщения.
3. Account Alerts → Connect Telegram → Open Telegram → Start в Vela Alerts bot.
4. Вернуться в Vela, проверить Your destinations и выбрать чат в Send to у созданного alert. Проверить Preview/Message checks: сообщение должно включать содержимое alert() с уровнями.
5. Дождаться Live, проверить лог доставки при реальном сигнале. Компьютер можно выключить: серверный alert работает независимо от вкладки.

Источник: https://docs.luxalgo.com/platform/ai-strategy-alerts/notifications

Код подготовлен, но компиляция и доставка не проверены в аккаунте. Telegram не подключён автоматически. Не публиковать приватную ссылку подключения.

Использовать только цены фактического источника: сигнал QQQ нельзя использовать как числовые уровни NAS100, а FOREX.com NAS100 может отличаться от Bybit. Если в Vela нет нужного инструмента, тот же Pine можно запускать на соответствующем графике TradingView; маршрут доставки Telegram там требует отдельной настройки.

Это индикатор, отчёта прибыльности не создаёт. Вход-ориентир не гарантирует исполнение по указанной цене, при задержке требуется повторная оценка уровней. Один сетап в NY-сессию, OR 09:30–09:45 NY, окно входа 09:45–10:30, будни. Не круглосуточный сканер крипты. Опциональное напоминание 11:30 не отслеживает позицию; уведомлений о фактическом достижении SL/TP нет.
