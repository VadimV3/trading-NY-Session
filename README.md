## Правила версий

Не редактировать v1.0.pine и исходный snapshot. Новая логика — новый файл v1.1.pine и отдельный отчёт, ветка и запись CHANGELOG. Данные проверок добавлять отдельными файлами; не заменять исходные цифры пересчётом. Git tag v1.0 фиксирует исходный архив.

Ожидание возврата ограничено и waitBars, и окном входов 09:45–10:30 NY. Не считать 30 минут гарантированным ожиданием после любого пробоя. Выход по времени в исходнике использует бар 11:25–11:30 и immediately=true; фактическое исполнение нужно проверить в платформе.

## Проверка архива

Из корня репозитория: `shasum -a 256 -c checksums.sha256`.
