# Развёртывание

Статус: подготовлены ручные инструкции, фактического развёртывания нет.

1. Выбрать Git tag/commit, проверить checksums.sha256 и открыть соответствующий .pine.
2. В целевой платформе открыть доступный Pine-редактор или подтверждённый интерфейс импорта, если он поддерживается. Названия и наличие функций проверить в текущем интерфейсе.
3. Вставить исходник полностью и выполнить компиляцию. Ошибки сохранить в отчёте; исправлять в новой версии, не переписывая v1.0.
4. Выбрать точный инструмент QQQ NASDAQ, стандартные свечи M5, источник котировок и сессию. Зафиксировать Inputs/Properties, комиссии и проскальзывание.
5. Запустить исторический тест; сверить CSV сделок, счётчики и агрегаты с baseline. Расхождения описать, а не подгонять исходник.
6. Перед любым подключением исполнения провести отдельную проверку в симуляции. Git push сам по себе не отправляет торговые заявки.
7. В журнале релиза записать tag, commit, hash, платформу, время, настройки и результат проверки.

Откат: загрузить сохранённый исходник предыдущего tag и прежние настройки, заново скомпилировать и проверить.

## API и автоматизация

Подтверждённого API LuxAlgo Vela для загрузки Pine, запуска тестов или развёртывания в этом архиве нет. Автоматический деплой не реализован и не обещан. GitHub хранит версии; будущий CI может проверять архив. Интеграцию с Vela/TradingView добавлять только после проверки официального API, авторизации и поддерживаемых действий. Сигналы/alerts/webhooks и развёртывание исходника — разные операции.
